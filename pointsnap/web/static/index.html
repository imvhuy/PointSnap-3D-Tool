    Dự án / Guideline

    Guideline của dự án

    Luật, ngưỡng và tiêu chí đạt áp dụng cho mọi lần quét của dự án. Lưu xong có hiệu lực từ lần quét sau.

    Cổng kiểm soát

    Job ĐẠT khi số mục không vượt các mức này. Dùng trên web, extension và pointsnap gate.

    Luật kiểm tra —

    Luật tắt sẽ không chạy khi quét. Rê chuột lên tên luật để xem mã luật.

    Ngưỡng lơ lửng / lún

    So đáy box với các frame khác của cùng track; box lẻ so trực tiếp với mặt đất. Ngưỡng Lỗi phải lớn hơn ngưỡng Cảnh báo.

    Khoảng kích thước theo class

    Dùng cho class ít mẫu (đơn vị mét, min – max); class nhiều mẫu lấy từ thống kê dữ liệu. Sửa trực tiếp trong bảng.
    Class Dài (min – max) Rộng (min – max) Cao (min – max) Thao tác
    Khi lưu, hệ thống kiểm tra cú pháp và giá trị; sai sẽ báo vị trí lỗi và không lưu. Ví dụ bộ nhãn giao thông VN: pointsnap/guidelines/spec-vn.yaml.

    Dự án / Kết nối CVAT

    Kết nối CVAT & dữ liệu

    Máy chủ CVAT, token và nơi chứa point cloud của dự án này.

    Máy chủ CVAT

    Lấy ở CVAT: avatar → Settings → Personal access tokens. Đổi địa chỉ CVAT sẽ xóa token cũ — nhập token của server mới.

    Dữ liệu point cloud

    Nơi chứa point cloud, ảnh camera và metadata nuScenes.
    Chứa manifest.json để khớp frame. Nhiều thư mục: phân cách bằng dấu ;.

    Extension trong CVAT

    Chưa thấy tab CVAT nào mở job của lần quét đang xem.
    1. Chrome / Edge mở chrome://extensions (Edge: edge://extensions).
    2. Bật Developer mode → Load unpacked → chọn thư mục source-tool/pointsnap-3d/extension.
    3. Mở job trên CVAT: bảng PointSnap hiện ở góc trang, tự lọc box có cờ.
    CVAT không ở localhost:8080? Bấm biểu tượng PointSnap trên thanh trình duyệt → Tùy chọn để thêm địa chỉ.
    Khi extension đang mở đúng job: chọn mục ở trang Kết quả thì CVAT tự chuyển tới box đó; kết luận và sửa box ở hai bên đồng bộ trong vài giây, không cần F5.
